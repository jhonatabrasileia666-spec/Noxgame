# Envio do NOX

Envie para esta pasta os três arquivos `nox.part01`, `nox.part02` e `nox.part03` disponibilizados na conversa do ChatGPT.

Quando os três estiverem aqui, o GitHub Actions unirá o pacote, extrairá `index.html` e `assets/` para a raiz do repositório e fará um commit de publicação automaticamente.

**Versão:** pacote editável de 30/10/2026 (não inclui necessariamente os últimos ajustes do site ativo).
