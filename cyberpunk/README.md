# NOX — Distrito Neon

Este capítulo cyberpunk jogável foi publicado separadamente para preservar o NOX original.

## Conteúdo
- 3 zonas: Pátio das Megatorres, Mercado da Chuva e Arena Corporativa
- 4 inimigos animados, 3 chefes com sprites de combate e a sprite original do mago NOX
- Movimento, ataque automático no celular, esquiva, meteoro, dano, 3 ondas por zona e progressão
- Menu de seleção de zonas para testar sem concluir as anteriores

## Controles
**Celular:** direcional esquerdo, esquiva e meteoro à direita; ataque automático.
**PC:** WASD/setas, Q/clique, R e espaço.

Abrir: ./index.html ou a rota /cyberpunk/ na publicação GitHub Pages.

> A versão original hospedada no ChatGPT Site não foi modificada. Este capítulo só poderá ser integrado ao mesmo código-fonte quando o pacote completo do NOX for importado no repositório.
